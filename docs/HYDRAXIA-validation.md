## Reproduced failure and engine fix

[Initial failing run](https://github.com/mrserluiz/Terra2.0/actions/runs/38054384327) loaded the pack, then crashed during generation with `ArrayIndexOutOfBoundsException: Index -1 out of bounds for length 176` in `BiomeTagHolder.get`, called by `SingleTagQuery.test` and cavern replacement extrusions.

An absent tag produced index -1 and was used directly as an array index. SingleTagQuery also cached an index without its originating pack table, which could return incorrect results if reused against another pack.

The generic fix treats absent tags as non-matching, resolves against the current biome's own immutable tag table, and uses constant-time map lookup. Regression tests cover absent tags, differently ordered pack tables, concurrent queries, duplicate tags and immutable snapshots. No HYDRAXIA-specific behavior was added to the production engine.

## Pack configuration caveat

The cavern extrusion file uses `from: SPRUCE_CAVERNS`. The current format queries tags, and biome identity is represented by the automatic tag `BIOME:SPRUCE_CAVERNS`. The supplied pack does not define a plain SPRUCE_CAVERNS tag. The engine fix prevents this rule from crashing; the rule itself does not match. If the author's intent is replacing that particular biome, change this one field to `from: BIOME:SPRUCE_CAVERNS` in a separately versioned pack, then validate its distribution. The preserved test fixture deliberately remains byte-for-byte identical to the supplied inner ZIP.

## Server test

Use the 7.0.21 engine JAR, then add the correctly packaged ZIP and restart the server once to load the Community Pack. Merge this binding into `plugins/Terra2/terra2-settings.yml`, preserving existing worlds and protected-worlds:

```yaml
generation:
  enabled: true
  protected-worlds:
    - world
    - world_nether
    - world_the_end
worlds:
  terra2_hydraxia_teste:
    pack: HYDRAXIA
```

Create a new authorized test world with Multiverse:

```text
/mv create terra2_hydraxia_teste normal -g Terra2:HYDRAXIA
/mv tp terra2_hydraxia_teste
```

A newly installed Community Pack requires a restart; settings reload alone does not register its legacy engine configuration. Existing chunks are not regenerated by changing a pack binding.
