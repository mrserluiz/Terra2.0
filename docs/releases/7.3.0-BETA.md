## Calibrar as cores

Com a ponte preparada, o arquivo `plugins/Terra2/bedrock/color-calibration.yml` é criado automaticamente. Começa neutro, pois as imagens mostram uma diferença visual mas não permitem calcular uma equivalência universal entre os renderizadores.

Compare Java e Bedrock na mesma posição, horário e condições. Como primeiro teste de folhagem menos pálida, use:

```yaml
roles:
  foliage: {saturation: 1.15, brightness: 1.0, hue-degrees: 0.0}
  grass: {saturation: 1.0, brightness: 1.0, hue-degrees: 0.0}
  water: {saturation: 1.0, brightness: 1.0, hue-degrees: 0.0}
biomes: {}
```

Este é um ponto de partida experimental, não uma correspondência comprovada ao Java. Evite clarear automaticamente: maior brilho pode piorar a aparência pálida. `hue-degrees` permite ajustar diferenças de tom se aumentar a saturação não resolver.

Para corrigir somente um bioma, coloque seu ID registrado exato (mostrado por `/terra2 biome`) em `biomes`:

```yaml
biomes:
  'terra:meu_pack/meu_bioma':
    foliage: {saturation: 1.15, brightness: 1.0, hue-degrees: 0.0}
```

Saturação e brilho aceitam 0..2; tom aceita -30..30 graus. Números inválidos impedem a preparação da ponte em vez de modificar a geração do mundo. Ajustes por bioma substituem o ajuste global daquele papel. Cores ausentes no perfil não são inventadas.

Reinicie após alterar a calibração, aceite o pack recompilado e reconecte. O conteúdo calibrado participa da identidade do pack; nenhuma edição manual dos PNGs ou do Geyser é necessária. Mantenha somente um pack Terra2 ativo, preservando packs de outros plugins.

A ponte continua exigindo mundo CUSTOM e Geyser-Spigot oficial local. Materiais com cor fixa podem não seguir o tint de bioma. A calibração não promete aparência idêntica entre iluminação, texturas ou modos gráficos diferentes.
