# Terra2 7.3.3-BETA — AETHER 0.2.0

New reusable native Minecraft density operators support Aether I's `old_blended_noise`, original vertical gradients and world-aligned cell interpolation. AETHER replaces its oval-island approximation with the translated density graph and introduces smaller trees with four distinct biome vegetation configurations.

Pack-level switches disable vanilla decoration and structures without changing existing packs' defaults. AETHER also disables structure bearding and retains zero carving. Other plugins' structure placement remains independently configured.

Requires Paper 26.2 and Java 25. Install `Terra2-bukkit-7.3.3-BETA.jar` together with `AETHER-0.2.0-terra2.zip`; the pack cannot load on 7.3.2. Create a new authorized test world. Keep primary worlds protected. Bedrock manifest/module version is `[7,3,3]`; calibration inheritance, explicit base colors and HSV are preserved. Supported native bridge remains official Geyser-Spigot 2.11.3 build 1251.

This terrain-first pack does not implement the complete Aether mod. Biome distribution and vegetation are Terra2 approximations, materials are vanilla stand-ins, and Aerclouds, Crystal Islands, Quicksoil, ores, original structures and Aether II remain later work.

Validation status and installation: [AETHER 0.2.0](../testing/AETHER_PACK_0.2.0.md), [pack guide](../../terra2-engine/tools/fixtures/aether/README.md).
