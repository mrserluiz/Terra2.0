# Terra2 7.4.0-BETA — Paper 26.3

Esta linha porta o motor independente para **Paper 26.3 build 231 / Java 25**. Para Paper 26.2, use a distribuição 7.3.5-BETA; o JAR nativo 7.4.0 não é anunciado como compatível com o 26.2.

## O que mudou no adaptador

- Etapas antigas de noise/surface/carvers adaptadas ao contrato `buildTerrain` do 26.3, preservando o gerador Bukkit/Terra e suas autorizações por mundo.
- BiomeSource adaptado ao resolvedor de biomas do novo sampler climático. A injeção também atualiza o resolvedor em cache do ServerLevel 26.3, evitando resposta vanilla para chunks descarregados. A instalação restaura o contexto anterior se falhar. IDs customizados continuam registrados e gravados nos chunks.
- Densidades compiladas pelo novo `DensitySampler`, com RandomState por seed e cache limitado. O operador old-blended usa a implementação nativa do jogo. O 26.3 usa saídas float; os testes de paridade explicitam essa precisão.
- Cores de céu e névoa convertidas entre RGB24 dos packs e os vetores RGB do 26.3. Grama, folhas e água conservam seus campos de cor. Testes cobrem a conversão de todos os valores de canal.
- Spawn de mobs adaptado a grupos com IntProvider e atributos de ambiente. Listas customizadas continuam substituindo as categorias do pack, e a probabilidade de criaturas é aplicada no atributo correspondente.
- Grafo privado de recursos adaptado aos registros e getters do 26.3: aliases de `configured_feature`, configurações de features, providers de blocos, offsets, grupos de spawn e tags. O loot antigo é traduzido para condições/modificadores tipados, listas explícitas all-of/sequence, referências privadas e ranges numéricos. Quantidade, nome e lore continuam executáveis; fontes originais não são sobrescritas.
- Partículas de bloco dos Community Packs traduzem os campos antigos de SNBT; processadores/geradores recebem os estados de bloco no codec atual. A ponte de loot intercepta o novo modificador opcional da tabela, mantendo os modificadores originais e limitando o tratamento a itens recém-gerados.
- Montagem de estruturas passa o sampler climático e a origem de placement exigidos pela API atual.
- Ponte nativa adaptada ao Geyser oficial 2.12.1 build 1279: provider de registros por sessão, registros mutáveis com freeze, preservação de entradas alheias e rollback em falhas. Não é um fork do Geyser e não altera registros globais.
- Manifesto do pack visual Bedrock acompanha a versão `[7,4,0]`; calibração global e por bioma permanece preservada.

O teste AETHER também verifica os IDs reais e as cores registradas, além da geometria, antes/depois de save/restart. Isso não equivale a um teste de renderização de cliente.

## Instalação e migração

1. Com o servidor desligado, mantenha backup do save anterior à atualização do Minecraft.
2. Remova o JAR antigo do Terra2 de `plugins` e instale somente `Terra2-bukkit-7.4.0-BETA.jar` no Paper 26.3 com Java 25.
3. Preserve `plugins/Terra2`, os Community Packs, o YAML de autorização e os mundos. Não instale o ZIP como plugin nem adicione o controlador fino junto ao motor.
4. Inicie e confira `/terra2 biome debug` nos mundos configurados. A atualização do plugin não autoriza novos mundos nem regenera chunks existentes.

Conversões nativas de datapacks são vinculadas ao DataVersion do servidor: reconverta as fontes para o 26.3 antes de executá-las. Uma conversão ainda marcada BLOCKED continua bloqueada. Este porte não conclui todos os recursos vanilla planejados nem confirma compatibilidade de plugins de terceiros.

O Minecraft 26.3 removeu o componente `minecraft:map_color`. Na conversão, o valor antigo é guardado em custom data (`terra2:legacy_map_color`) quando possível; ele não recolore mapas no cliente. Tags vanilla antigas de mapas exploradores são traduzidas para os destinos atuais.

O perfil GENERATION_AND_LOOT continua sem instalar funções/quests/gameplay do datapack original. Validação dos codecs não demonstra a execução de todos os eventos do pack. Um Community Pack com SNBT fora do subconjunto suportado (como o `end_gateway` legado do ReimagEND observado no teste) continua recusado, sem autorização para alterar mundos.

Para Paper 26.3, atualize também o **Geyser-Spigot oficial para 2.12.1 build 1279**. O 2.11.3 build 1251 falhou ao habilitar no 26.3 (busca de método CraftItemStack), antes de qualquer ponte do Terra2. A recomendação histórica de Geyser 2.11.3 na linha 7.3.5 / Paper 26.2 não se aplica à 7.4.0. A ponte continua usando o Geyser oficial. Testes de transporte e registros não confirmam por si só download/aceitação do pack, reconexão ou cores no cliente Bedrock. O problema de registro de biomas que o usuário identificou no pack deve ser validado também na versão corrigida desse pack.

## English summary

Native Paper 26.3 / Java 25 port: terrain construction, biome resolvers, compiled density samplers, RGB environment attributes, mob spawning, private registries, structure placement and legacy loot codecs. Per-world authorization, protected primary worlds and existing user calibration are retained. The native 26.2 distribution remains 7.3.5-BETA. Native datapack conversions must match the new server DataVersion and may need reconversion. Update the official Geyser-Spigot to 2.12.1 build 1279 for Paper 26.3; 2.11.3 does not start on this target. All five CI jobs passed, and an unmodified CI JAR preserved 4,608 real biome cells plus five color profiles when migrating a saved 26.2 world. Real client rendering remains an acceptance test.
