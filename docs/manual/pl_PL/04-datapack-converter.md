# Konwerter datapacków vanilla

[Podręcznik użytkownika](README.md) · **Terra2 7.0.14-BETA**

Umieść ZIP lub folder datapacka z pack.mcmeta w plugins/Terra2/conversion/input/. Uruchom konwersję i sprawdź raport. READY oznacza obsługiwany wykonywalny zakres; BLOCKED nie może być użyty. Wersja 7.0.14 nie jest uniwersalnym konwerterem.


```text
plugins/Terra2/conversion/input/
plugins/Terra2/conversion/reports/
plugins/Terra2/terrapacks/

/terra2 convert Plano flat-demo terra2_demo:flat
/terra2 convert Debris scatter-demo
/terra2 packs inspect Plano
/terra2 packs inspect Debris
```
