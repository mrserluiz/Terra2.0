# Определение и поиск биомов и структур — 7.0.23-BETA

```text
/terra2 biome
/terra2 structures [radius]
/terra2 locate biome <ID> [radius]
/terra2 locate structure <ID> [radius]
```

`terra2.settings.reload` · OP · Tab

Радиус: 32..8192 блоков.

Индекс сохраняется по UUID и seed мира в `plugins/Terra2/structure-index/` каждые пять секунд и при нормальном выключении. Старые паки показывают ID features этапа `structures`; шаблоны и старые чанки не восстанавливаются задним числом. Нативные структуры показывают исходные ID. Максимум 100 000 позиций на мир. Поиск биомов на вашем Y, сетка 32 блока, до 16 384 запросов или двух секунд между запросами. Чанки не создаются.

Индексированные опорные точки: `[ID, XYZ]`. Лимит индекса достигнут: `true/false`. Только созданные/индексированные позиции; не доказывает нахождение внутри.

Образец найден: `ID` [X, Y, Z]. На вашем Y; сетка 32 блока, ближайший не гарантирован.

Образец не найден до лимита радиуса/времени/запросов (N образцов). Это не доказывает отсутствие.
