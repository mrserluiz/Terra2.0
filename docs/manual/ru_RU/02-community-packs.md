# Паки сообщества Terra

[Руководство пользователя](README.md) · **Terra2 7.0.14-BETA**

Скачайте совместимый пак оригинального Terra и распакуйте его в plugins/Terra2/packs/<pack>/ так, чтобы pack.yml находился в корне пака. Используйте зарегистрированный ID, который может отличаться от имени папки. Конвертация оригинальных паков Terra не нужна.


```text
plugins/Terra2/packs/OVERWORLD/pack.yml
plugins/Terra2/packs/TARTARUS/pack.yml
```
