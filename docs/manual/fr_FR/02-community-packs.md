# Packs communautaires Terra

[Manuel utilisateur](README.md) · **Terra2 7.0.14-BETA**

Téléchargez un pack Terra original compatible et extrayez-le dans plugins/Terra2/packs/<pack>/ avec pack.yml à la racine. Utilisez l'identifiant chargé, parfois différent du dossier. Les packs Terra originaux n'ont pas besoin de conversion.


```text
plugins/Terra2/packs/OVERWORLD/pack.yml
plugins/Terra2/packs/TARTARUS/pack.yml
```
