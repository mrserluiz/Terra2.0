# Convertisseur de datapacks vanilla

[Manuel utilisateur](README.md) · **Terra2 7.0.14-BETA**

Placez le ZIP ou dossier du datapack avec pack.mcmeta dans plugins/Terra2/conversion/input/. Convertissez puis consultez le rapport. READY est exécutable dans les limites prises en charge ; BLOCKED ne l'est pas. La version 7.0.14 n'est pas un convertisseur universel.


```text
plugins/Terra2/conversion/input/
plugins/Terra2/conversion/reports/
plugins/Terra2/terrapacks/

/terra2 convert Plano flat-demo terra2_demo:flat
/terra2 convert Debris scatter-demo
/terra2 packs inspect Plano
/terra2 packs inspect Debris
```
