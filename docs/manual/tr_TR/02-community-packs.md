# Terra topluluk paketleri

[Kullanıcı kılavuzu](README.md) · **Terra2 7.0.14-BETA**

Uyumlu bir orijinal Terra paketini indirip pack.yml paket kökünde olacak şekilde plugins/Terra2/packs/<pack>/ klasörüne çıkarın. Klasör adından farklı olabilen kayıtlı paket kimliğini kullanın. Orijinal Terra paketleri dönüştürme gerektirmez.


```text
plugins/Terra2/packs/OVERWORLD/pack.yml
plugins/Terra2/packs/TARTARUS/pack.yml
```
