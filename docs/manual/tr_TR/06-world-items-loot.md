# Gelecek: dünyaya özel eşyalar ve ganimet

[Kullanıcı kılavuzu](README.md) · **Terra2 7.0.14-BETA**

Planlanıyor, 7.0.14'te etkin değil: dünyaya özel ganimet, oluşturulan sandık kimliği, eşya kökeni, doğal ve oyuncu yerleştirmesi bloklar, edinme ve kullanım kısıtları.


```yaml
# FUTURE EXAMPLE ONLY — NOT SUPPORTED IN 7.0.14
world-loot:
  aeternum_aether:
    minecraft:chests/simple_dungeon:
      mode: REPLACE
      with: AETHER:DUNGEON
items:
  AETHER:DUNGEON_KEY:
    obtain-only-in: [aeternum_aether]
    usable-in: [aeternum_aether]
```
