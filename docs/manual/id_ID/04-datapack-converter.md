# Konverter datapack vanilla

[Panduan pengguna](README.md) · **Terra2 7.0.14-BETA**

Letakkan ZIP atau folder datapack yang memiliki pack.mcmeta di plugins/Terra2/conversion/input/. Konversi dan periksa laporan. READY dapat dijalankan dalam batas dukungan; BLOCKED tidak. Versi 7.0.14 bukan konverter universal.


```text
plugins/Terra2/conversion/input/
plugins/Terra2/conversion/reports/
plugins/Terra2/terrapacks/

/terra2 convert Plano flat-demo terra2_demo:flat
/terra2 convert Debris scatter-demo
/terra2 packs inspect Plano
/terra2 packs inspect Debris
```
