# Instalasi dan konfigurasi

[Panduan pengguna](README.md) · **Terra2 7.0.14-BETA**

Pasang JAR Terra2 di plugins/ saat server berhenti. Mulai ulang, aktifkan generasi, dan izinkan dunia uji baru dalam pengaturan dunia Terra2. Jangan menimpa config.yml mesin Terra lama.


```yaml
generation:
  enabled: true
  protected-worlds: [world, world_nether, world_the_end]
worlds:
  terra2_teste:
    pack: OVERWORLD
```
