# Paket komunitas Terra

[Panduan pengguna](README.md) · **Terra2 7.0.14-BETA**

Unduh paket Terra asli yang kompatibel dan ekstrak ke plugins/Terra2/packs/<pack>/ dengan pack.yml di akar paket. Gunakan ID paket yang terdaftar, yang bisa berbeda dari nama folder. Paket Terra asli tidak perlu dikonversi.


```text
plugins/Terra2/packs/OVERWORLD/pack.yml
plugins/Terra2/packs/TARTARUS/pack.yml
```
