# Weltbefehle und Übersetzungen

Dieses Kapitel gilt für 7.0.22-BETA; ältere Kapitel behalten die angegebene Referenzversion.

```text
/terra2 lis Cpack
/terra2 lis Tpack
/terra2 lis all
/terra2 unlock terra2_teste OVERWORLD
/terra2 unlock terra2_mix OVERWORLD;Debris
```

Registrierte Community Packs: OVERWORLD, TARTARUS, HYDRAXIA

Welt terra2_teste für OVERWORLD freigegeben. Einstellungen gespeichert; Generierung für freigegebene Welten aktiviert.

Keine Welt wurde erstellt oder neu generiert. Für eine neue Welt: /mv create terra2_teste normal -g Terra2:PACKS

Welt world ist geschützt. Dieser Befehl hebt keinen Schutz auf. YAML manuell prüfen; die primären Vanilla-Welten bleiben durch die Engine gesperrt.

Welt terra2_teste ist geladen. Ihr Generator kann im laufenden Betrieb nicht ersetzt werden; die Welt zuerst sicher entladen.

YAML-Änderungen umgehen nicht den Schutz der Engine für primäre Vanilla-Welten. Nur das erste Pack darf eine Community-Geländebasis sein. Gespeicherte Freigaben schreiben vorhandene Chunks nicht neu und ersetzen keinen bereits gebundenen Generierungsplan.
